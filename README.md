# 고려와 불교 마블 — 사회 5-2 1단원

「고려와 불교」 복습 보드게임(부루마블식). 전자칠판 한 화면에서 4모둠이 돌아가며 주사위를 굴린다.
서버·동기화 없음. `index.html` 을 더블클릭해서 열어도 된다(글꼴 Jua 는 인터넷이 될 때만).

수업 40분 = 규칙 설명 5분 + 플레이 30분 + 결과 5분.

## 규칙

- 4모둠, 곡식 500섬으로 시작. 1모둠부터. 주사위 2개 합만큼 간다(더블 보너스 없음).
- 개경을 지나거나 도착하면 +100.
- **빈 땅** — 그 땅 문제(3지선다). 맞히면 [산다]/[안 산다], 틀리면 해설만 보고 못 산다.
- **우리 땅** — [연등 달기]. 1개 = 땅값의 절반, 한 땅에 2개까지.
- **남의 땅** — 통행료 = 기본 통행료 × (1 + 연등 수). 같은 구역 4칸을 한 모둠이 다 가지면 ×2.
- **연등 카드** — 8장을 섞어 한 장씩. 다 쓰면 다시 섞는다. 카드로 앞으로 가다 개경을 지나면 +100(몽골 침입 카드만 빼고).
- **몽골 침입** — 다음 자기 차례를 한 번 쉰다(카드로 가도 같다).
- **팔관회** +100. **연등회** — 우리 땅 하나에 연등 1개 공짜. 달 땅이 없거나 다 꽉 찼으면 +50.
- 파산 없음. 모자라면 마이너스(빚).
- 시간이 끝나면 진행 중인 차례까지만 하고 결과. 아직 주사위를 안 굴렸으면 바로 결과.
- 점수 = 곡식 + 가진 땅값 + 단 연등값.

땅을 살 때·연등을 달 때는 곡식이 있어야 한다(빚으로 사지는 못한다). 통행료만 빚이 될 수 있다.

## 교사 단추 (가운데 오른쪽 위 [교사])

| 단추 | 하는 일 |
| --- | --- |
| 되돌리기 | 직전 차례가 시작될 때로. 주사위를 이미 굴렸으면 이번 차례 시작으로 |
| 곡식 조정 | 모둠을 고르고 ±10·50·100 |
| 말 옮기기 | 모둠을 고르고 보드 칸을 누른다. 칸 효과 없음. 주사위 굴리기 전에만 |
| 시간 멈추기 | 타이머를 멈춘다(주사위도 잠긴다) |
| 지금 끝내기 · 새 게임 | 확인을 한 번 묻는다 |

시작 화면에서 모둠 이름 4개, 플레이 시간(5분 단위, 기본 30분), 효과음을 정한다.

## 저장

모든 상태는 이 브라우저의 `localStorage`(`goryeoMarble.v1`)에 바로바로 저장된다.
새로고침·창 닫기 후에도 같은 차례·곡식·땅·열려 있던 문제 창까지 이어진다.
타이머는 화면이 열려 있는 동안만 줄어든다. 주사위 결과는 굴리는 순간 저장되므로 새로고침으로 다시 굴릴 수 없다.

## 파일

- `data.js` — 보드 20칸·땅 문제 12개·연등 카드 8장. 문장은 복습 사이트 기준이라 고치지 않는다. 정답은 항상 첫 번째(화면에서 섞는다).
- `index.html` — 화면·규칙 전부.
