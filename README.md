# 고려 마블 — 사회 5-2 1단원 고려 (13~19차시)

고려 전체(성립·대외 교류·생활·불교·문화) 복습 보드게임(부루마블식). 전자칠판 한 화면에서 4모둠이 돌아가며 주사위를 굴린다.
서버·동기화 없음. `index.html` 을 더블클릭해서 열어도 된다(글꼴 Jua 는 인터넷이 될 때만).

수업 40분 = 규칙 설명 5분 + 플레이 30분 + 결과 5분.

## 규칙

- 2~6모둠(시작 화면에서 고름), 곡식 500섬으로 시작. 1모둠부터. 주사위 2개 합만큼 간다(더블 보너스 없음). 보드는 24칸.
- 개경을 지나거나 도착하면 +50.
- **빈 땅** — 그 땅 문제. 맞히면 [산다]/[안 산다], 틀리면 해설만 보고 못 산다.
- **우리 땅** — [연등 달기]. 1개 = 땅값의 절반, 한 땅에 2개까지.
- **남의 땅** — 그 땅 문제가 먼저 나온다. **맞히면 통행료 절반**, 틀리면 다 낸다.
- 통행료 = 기본 통행료(땅값의 80%) × 연등 배수(0개 ×1, 1개 ×2, 2개 ×4) × 같은 색 4칸 독점 ×2.
- **물가 상승** — 남은 시간이 10분(짧은 판은 전체의 1/3)이 되면 모든 통행료 ×1.5.
- **연등 카드** — 12장을 섞어 한 장씩. 다 쓰면 다시 섞는다. 곡식을 잃는 카드도 있다.
- **몽골 침입** — 다음 자기 차례를 한 번 쉰다(카드로 가도 같다).
- **팔관회** +100. **연등회** — 우리 땅 하나에 연등 1개 공짜. 달 땅이 없거나 다 꽉 찼으면 +50.
- 파산 모드가 꺼져 있으면 파산 없음. 모자라면 마이너스(빚).
- 시간이 끝나면 그 바퀴의 마지막 모둠까지 하고 결과.
- 점수 = 곡식 + 가진 땅값 + 단 연등값.

| 구역 | 땅 | 땅값 | 기본 통행료 |
| --- | --- | --- | --- |
| 고려를 세우고 지키다 | 왕건과 고려 · 서희의 담판 · 나라를 지킨 싸움 · 몽골에 맞서다 | 100 | 80 |
| 세계와 만나고 함께 살다 | 국제 무역항 · 주고받은 물건 · 고려의 신분 · 고려의 가족 | 140 | 110 |
| 고려와 불교 | 나그네의 하룻밤 · 어려운 이웃 돕기 · 등불 행렬 · 나라의 큰 잔치 | 160 | 130 |
| 고려의 문화유산 | 나무에 새긴 글 · 목판 보관소 · 고려의 인쇄술 · 도자기 이야기 | 200 | 160 |

통행료 숫자는 모의 게임 2,000판으로 맞췄다(30분 · 모둠당 8차례 기준).
1판보다 한 판에 오가는 통행료가 약 1.8배이고, 5판 중 1판꼴로 빚지는 모둠이 생긴다.

땅을 살 때·연등을 달 때는 곡식이 있어야 한다(빚으로 사지는 못한다). 통행료와 카드만 빚이 될 수 있다.

## 시작 화면에서 고르는 것

**문제 고르기** (체크 단추, 하나 이상)

| 묶음 | 문제 수 | 보드 |
| --- | --- | --- |
| 고려 (13~19차시) | 50 | 세계 보드 |
| 1단원 총정리 (1~19차시) | 105 | 세계 보드 |

보드는 언제나 세계 보드(나라·도시 이름, 돈(만 원)·건물·황금 열쇠). 고른 문제 전체에서 무작위로 나온다.
같은 판에서는 고른 문제를 다 쓰기 전까지 같은 문제가 다시 나오지 않는다.
문제 은행은 `bank.js` 의 `BANK`(차시 묶음 `set` 표시). 나중에 차시별 체크로 나누려면 `PACKS` 에 묶음을 더하면 된다(`SETS` 목록 참고).

**규칙 고르기**

- **꼴찌 응원** (기본 켬) — 꼴찌 모둠이 출발점을 지나면 +150 더. 실력이 같은 모둠끼리 모의 150판: 1등이 꼴찌의 3배 이상인 판 31% → 16%.
- **파산 모드** (기본 끔) — 빚이 생기면 가진 땅을 싼 것부터 (땅값 + 연등값)의 절반에 자동으로 팔아 갚는다. 그래도 모자라면 탈락. 탈락한 모둠은 차례를 건너뛰고 결과에서 맨 아래. 한 모둠만 남으면 바로 끝.

시간이 끝나면 **그 바퀴의 마지막 모둠까지** 하고 끝낸다(모든 모둠이 같은 횟수).

## 교사 단추 (가운데 오른쪽 위 [교사])

| 단추 | 하는 일 |
| --- | --- |
| 되돌리기 | 직전 차례가 시작될 때로. 주사위를 이미 굴렸으면 이번 차례 시작으로 |
| 곡식 조정 | 모둠을 고르고 ±10·50·100 |
| 말 옮기기 | 모둠을 고르고 보드 칸을 누른다. 칸 효과 없음. 주사위 굴리기 전에만 |
| 시간 멈추기 | 타이머를 멈춘다(주사위도 잠긴다) |
| 지금 끝내기 · 새 게임 | 확인을 한 번 묻는다 |

시작 화면에서 모둠 이름 4개, 플레이 시간(5분 단위, 기본 30분), 효과음을 정한다.

## 저장

모든 상태는 이 브라우저의 `localStorage`(`goryeoMarble.v2`)에 바로바로 저장된다.
새로고침·창 닫기 후에도 같은 차례·곡식·땅·열려 있던 문제 창까지 이어진다.
타이머는 화면이 열려 있는 동안만 줄어든다. 주사위 결과는 굴리는 순간 저장되므로 새로고침으로 다시 굴릴 수 없다.

## 파일

- `data.js` — 보드 24칸 · 땅 16칸의 문제 묶음(모두 50문제: 3지선다 · O/X · 사진) · 연등 카드 12장.
  문장은 복습 사이트(13~19차시 카드·확인 문제) 기준. 정답은 항상 첫 번째(화면에서 섞는다).
  같은 판에서는 그 땅의 문제가 다 나오기 전까지 같은 문제가 다시 나오지 않는다.
- `img/` — 사진 문제 3장(고려청자, 장경판전 안 대장경판, 장경판전).
- `index.html` — 화면·규칙 전부.
